# Prior boundary

Audit date: 2026-10-15. Exact model revisions and installed source hashes accompany the results.
Claims below describe prior work. They are not measurements from this PoC.

| Prior | Problem, model, and hardware | Training and method | Boundary for this PoC |
|---|---|---|---|
| [Ouro](https://ouro-llm.github.io/) and [official checkpoint](https://huggingface.co/ByteDance/Ouro-2.6B-Thinking) | Pretrained full-stack recurrence. Its official serving page pins vLLM0.26 as the last native version | Original training produces the recurrent model. Native serving executes all four loops | Recurrence, independent loop KV, and native head TP are not new. Released tensors override inconsistent card layer counts |
| [Huginn](https://huggingface.co/tomg-group-umd/huginn-0125) and [official code](https://github.com/seal-rg/recurrent-pretraining) | Pretrained prelude/core/coda model. Training used MI250X hardware. The experimental inference plugin documents TP1 | Original recurrent training. Native dynamic cache supports full and fallback/compressed policies | Do not replace its cache with ordinary layer indexing. Do not claim TP4 from an autogenerated website command |
| [FlashLoop](https://arxiv.org/html/2609.29812v1), [official implementation](https://github.com/Superone77/FlashLoop) | Repeated-loop compute and KV growth. Reported efficiency experiments use one A100-SXM4-40GB | Training-free token updates, sparse attention, and quantized KV residuals | Loop similarity, stale/converged-state reuse, and base-plus-residual storage are covered prior. They are excluded here |
| [MELT](https://arxiv.org/html/2605.07721v1) | Depth-dependent cache growth in Ouro. Main training uses eight H10080GB GPUs | Trained gated shared KV, initialized from Ouro and distilled | A new learned shared cache is not an exact placement change. Its training-node count is not an inference-TP result |
| [Looped Latent Attention](https://arxiv.org/abs/2607.15456) | Loop-indexed cache compression in Ouro and Huginn. The reported capacity example uses one H200 | SVD initialization and distillation of a latent codec | Cross-loop low rank and reconstruction are covered. No codec is proposed here |
| [Hybrid Latent Attention](https://arxiv.org/abs/2610.07940) | Long-context recurrent KV. Ouro1.4B/2.6B are evaluated | Frozen-base uptraining of direct latent attention plus an exact recent window | It changes the learned attention representation. No comparable hardware timing is borrowed from its results |
| [Enabling Dynamic Computation](https://arxiv.org/abs/2610.09013) | Missing deeper KV after early exits in Ouro | Best-available KV inference, with separately trained variants | Cache fallback and dynamic depth are covered. This PoC keeps fixed full depth and exact original caches |
| [Continuous Depth Batching](https://arxiv.org/html/2608.09444v1) | Heterogeneous exit depth and batching. Physical experiments use one H10080GB | Depth queues, lookahead exits, graphs, asynchronous preparation, and shared KV | Depth-aware batching and generic launch overlap are covered. A single-GPU result is not a multi-GPU placement result |
| [WaveFront](https://arxiv.org/html/2609.23033v1), [official code](https://github.com/summerbro-hhj/wavefront-decoding) | Sequential recurrent decode. Physical experiments use an RTX A6000 | Training-free, mixed-depth self-speculation. Rejected work and optional recurrence sharing are explicit | Different tokens can overlap through speculation. We cannot assume exact dependent loops execute independently |
| [LoopSpec](https://arxiv.org/html/2609.17184v1), [official code](https://github.com/kaist-flexml-lab/loopspec) | Recurrent decode latency. Physical implementation uses SGLang on RTX PRO6000 Blackwell | Training-free pipelined proposals and exact verification, with depth-specific cache management | Intermediate predictions and pipelined self-drafting are covered. No speculative mechanism is implemented here |
| [Parallel Loop Transformer](https://arxiv.org/abs/2510.24824) | Sequential loop cost | A trained architecture changes dependencies and shares first-loop KV | It is not an exact execution policy for the two original checkpoints. Its reported hardware is not used to predict this server |
| [Training-Free Looped Transformers](https://arxiv.org/abs/2605.23872) | Converting frozen ordinary models into recurrent inference | Inference wrappers and damped block reapplication | This campaign serves checkpoints already trained with recurrence. It does not retrofit loops |

HLA and the dynamic-computation paper do not supply a calibrated four-GPU latency model for this campaign.
Unverified prior hardware fields remain unknown. They do not become assumptions in our cost model.

## Generic multi-GPU execution

[Megatron tensor parallelism](https://arxiv.org/abs/1909.08053) already partitions projections and FFNs with reductions.
[PagedAttention](https://arxiv.org/abs/2309.06180) already separates logical token storage from physical cache pages.
[Ring Attention](https://arxiv.org/abs/2310.01889) already partitions context with communication and attention accumulation.
[FlashAttention](https://arxiv.org/abs/2205.14135) already preserves exact softmax through tiled statistics.
Distributed softmax merging and Q/KV transfer are not new by themselves.

Our question requires a physical shortfall beyond these standard choices.
Logical 1/TP head payload, additional aggregate HBM, or a poor reference cache layout cannot establish novelty.
Any candidate must include all remote data, hidden transfers, reductions, synchronization, and workspace.
No measured result from another model/runtime is substituted for that ledger.

## Experimental claim limit

No prior method is reproduced as a performance baseline in this cheap discovery campaign.
The primary comparison is each model's supported, fixed-depth native execution.
Huginn TP blockage prevents a two-family physical placement claim.
An unexplored publication niche is not a GO criterion.
