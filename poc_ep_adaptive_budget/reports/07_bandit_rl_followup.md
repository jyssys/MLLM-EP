# 07 — Bandit/RL follow-up decision

Contextual bandit and RL were not trained. A controller with a strong
future-aware full-trajectory oracle and demonstrated EP-specific improvement
would have to fail before either learning method becomes justified. The
present phase-only direct gain is below promoted implementation thresholds;
EP-cost incremental value and risk calibration are unestablished.

Moreover, training-free/dynamic token-commitment and learned unmasking policy
work already exists; see [prior-art audit](10_prior_art.md). Adding an EP
penalty to an existing unmasking reward, without a physical EP increment over
confidence+live-M and a clear action structure, would not constitute an
independent systems contribution. The next investigation, if any, should be
a better quality-valid baseline and a **cheap** EP-conditioned oracle rather
than RL engineering.
