## Scope limits

The source count is not a research-time measure.
Metadata observations are not deep reads.
Configuration controls are not candidate inventions.
Multiple variants of one algebraic identity are not separate execution axes.

The campaign did not repeat stale/delta hidden-state substitution.
It did not retrain a gate, learn a predictor, quantize the model, or switch the empirical target.
It did not duplicate the completed CDB factorial experiment.
The current search leaves further mechanisms open, but it does not claim untested novelty.
