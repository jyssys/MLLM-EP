# Modality-dependent MLLM architecture landscape

CogVLM2's visual decoder bank and IDEFICS-9B's dedicated cross-attention over fixed visual memory expose two different placement constraints. ERNIE 4.5 VL adds an independent checkpoint for the weight-residency hypothesis, with shared attention and modality-separated routed FFNs. The registry records source reachability, tensor storage and input eligibility. Runtime evidence appears in the corresponding experiments.

## Public checkpoints and executable boundaries

All rows with a pinned checkpoint were publicly readable without Hub gating when inspected. Model licenses and upstream runtime support vary. `Context` is the model config's configured position limit, where available. Coverage of Discovery200 still requires each model's native processor, per-image and total input limits, and room for its output cap. A source-level multi-image interface does not establish that a request with dozens of pages fits.

## Parameter and memory scope

The safetensors rows are verified against actual tensor names, shape and data-offset metadata. They represent **stored tensor elements**, including any serialized buffers. Internal weight totals below use decimal billions. Payload is GiB from the tensor header data range. It excludes CUDA cache, optimizer state, activation workspaces and runtime KV allocation. Logical activity is indicated per phase when the graph establishes it. For ordinary top-k MoE, estimate the structurally reachable D state from non-routed tensors plus the top-k share of routed tensors. This estimate includes the full vocabulary matrices and differs from published active-FLOP conventions. It gives no live block residency or EP traffic result.

## Dynamic depth and prior conditional routing

LoopLook describes question-conditioned recurrent visual layers, a learned stopping head and a Mixture-of-Looks. Its recurrent E↔question dependency is directly relevant to architecture-first scheduling. The paper identifies public **base models**. The reviewed paper and release pointers did not identify a downloadable checkpoint and runtime for the trained LoopLook variant. MuE has a public OFA-based implementation with input-dependent early exits for image/text encoding and decoding. Its released harness targets its captioning/classification protocol and describes trained checkpoints through its recipe. A compatible general Discovery200 instruction checkpoint was not verified. Both remain research-relevant source screens with a new native runtime gate. [LoopLook](https://arxiv.org/html/2610.30824v1) · [MuE, CVPR 2023](https://openaccess.thecvf.com/content/CVPR2023/html/Tang_You_Need_Multiple_Exiting_Dynamic_Early_Exiting_for_Accelerating_Unified_CVPR_2023_paper.html) · [MuE source](https://github.com/ncsu-dk-lab/MuE)

SMoES v2 has direct prior art for trained modality-aligned expert bins and EP placement. Its implementation description establishes the training and deployment mechanisms, including inference without an extra modality estimator. The publisher links in the paper are to the constituent DeepSeekMoE, OLMoE, Moonlight and Qwen3 base backbones. A released checkpoint for the exact SMoES-trained model was not verified, so loading a linked backbone would not instantiate the proposed specialization. Ordinary fixed-top-k models and the public Uni-MoE-2.0 differ in their actual conditional graph and need their own evidence. [SMoES v2 and supplementary implementation](https://arxiv.org/html/2604.23996v2)

## Selection

CogVLM2 and IDEFICS provide different executable boundaries within the GPU and artifact budget. ERNIE is the third native probe and tests whether a text-only D route also occurs with shared attention and routed, narrower visual FFNs. XComposer2 and Uni-MoE-2.0 require more runtime integration. OCR2's asymmetric mask is an E-only source probe. BAGEL and Janus provide controls for image→text deployments with dormant output-mode state. [Novelty audit](mllm_architecture_prior_work_novelty_audit.md)

For ERNIE, the publisher's processor imports the video decoder and attempts to fetch a font at import time. The local overlay pins the publisher source digests and disables those video paths and external media reads. The vLLM CPU registry resolved the original architecture and packed the synthetic text-only, one-image and two-image cases into 40, 128 and 260 tokens. The two-image case preserved both image spans of 81 and 126 tokens. The published config, model weights, tokenizer, chat template and local image preprocessing path supply the probe.
