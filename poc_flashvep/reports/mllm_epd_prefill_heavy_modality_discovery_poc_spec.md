# Prefill-heavy Dense MLLM EPD discovery

The primary model is Qwen2.5-VL-7B-Instruct at cc594898137f460bfe9f0759e9844b3ce807cfb5. Run BF16 1E/1P/1D on H200 GPUs 4–6 with native FlashAttention, CUDA IPC encoder embeddings and NIXL prompt KV. The registered primary budgets are P8192/D8192, S128 and 42 GiB each on P and D. All request-level prefix and encoder reuse is disabled. CUDA IPC ownership keeps the current request's original encoder buffers until consumers acknowledge and the request retires.

The native grid uses finite open-loop Poisson cohorts. E/P/D stage-only probes use identical input rosters and original batch/transfer semantics. They exclude off-stage work from the measured stage intervals. A one-token P probe isolates the stage; full serving fixed output ranges from 16 to 256. Pilot QPS is calibrated from each cohort's standalone P rate. Controlled visual-ratio requests use complete processor-generated visual spans and are distinct from unchanged natural questions. Quality requires original input.

The central observation window spans scheduled-arrival percentiles 20–80. P-heavy requires a real compute-ready queue, 80% P kernel union, 85% matched isolated P rate, ≤30% D kernel union as an initial target, and protected absolute Decode SLO, with supplier and admission evidence from the same valid window. Encoder-busy additionally targets 80% E kernel union and measured joint occupancy with D idle. End-to-end serving reports finite-cohort drain and overload queue growth. Sustainable capacity requires a stable operating interval.

Use clean-before/profile/clean-after on identical arrivals and original greedy outputs. The frozen observer tolerance is 5% for latency and duration metrics, including clean A/A variation. CUPTI gaps and checksum failures invalidate kernel data for qualification. The detailed observer samples true P scheduler conditions, and the lean observer records kernel activity without Python scheduling hooks. GPM supplies actual hardware utilization counters. Sampled or HTTP idle, activity union, observed copy gaps and deadline-safe slack have different coverage.

The historical absolute SLO is TTFT ≤5,000 ms, TPOT ≤33 ms, and every client ITL ≤34 ms. Strict decode protection limits TPOT p95 and ITL p99 degradation to 5%. A measured generic whole-request control may show service-level gain within absolute SLO with a failed relative gate. The policy classifications and both criteria remain fixed. A modality proposal needs additional physical or online value against a cost-aware whole-request control with exact original prompt semantics and same GPU budget.
