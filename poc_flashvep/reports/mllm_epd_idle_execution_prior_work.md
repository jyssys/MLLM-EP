Audit as of 2026-11-28. `UNVERIFIED` means the complete public runnable implementation was unavailable for source comparison. ## Prior physical evidence and the comparison it requires

- Qwen2.5-VL-7B H200 1E/1P/1D natural Very-long Fixed16 showed E/P/D kernel busy around 90.04/89.91/9.55% and a 72.61% joint E/P-busy and D-idle intersection in a common N64 window. The observer guard failed. D kernel-idle and proxy request-free windows had p50 627 ms and p95 935 ms. With a recent P-ready observation the p50/p95 narrowed to 270/568 ms. Post-hoc fit gave 24 P-ready opportunities for 500 ms work and zero for 1,150 ms. The previous D-local whole-prefill median was 1,149 ms. These are `DIAGNOSTIC` and `OFFLINE_ORACLE` scope. [Actual idle decomposition](https://github.com/jyssys/MLLM-EP/blob/f5d6d70d750ea7b0a2c9f0599e874c07d4a5409b/poc_flashvep/reports/mllm_epd_decode_idle_fragmentation.md)
- Matched inline Native vs Naive D-local whole-request on natural N24 reduced TTFT p95 from 10.519 to 7.486 s and raised goodput from 0.384 to 0.852 req/s. TPOT p95 rose 41.4% and ITL p99 102.0%. D B4096 also missed strict protection. Natural-EOS N64 had 6 actual D-local requests and 4/6 exact token sequences, with 53/64 exact sequences overall. The E-vs-D physical intervention kept an auxiliary LM on E in both arms and showed that moving the same whole work to D interfered less with E. It still hurt ITL relative to the matched no-assistance control. Preserve these useful same-GPU controls as baselines. [Whole-request](https://github.com/jyssys/MLLM-EP/blob/f5d6d70d750ea7b0a2c9f0599e874c07d4a5409b/poc_flashvep/reports/mllm_epd_whole_request_deflection.md) · [E/D intervention](https://github.com/jyssys/MLLM-EP/blob/f5d6d70d750ea7b0a2c9f0599e874c07d4a5409b/poc_flashvep/reports/mllm_epd_encoder_vs_decode_assistance.md)
- Prior H200 image-aware token split removed a transport artifact by slicing encoder rows. Only 7 KiB median additional E TX remained for an adjacent interior cut versus a hard boundary after both used the correct slice path. ## F's exact execution contract and physical discriminator

The pinned 7B checkpoint specifies 32 vision blocks, 1280 vision width, full-attention blocks 7/15/23/31, 14-pixel patch size, temporal patch size 2, merge size 2 and 112-pixel window size. The native Conv3d patch embedding uses a stride equal to its kernel. Native window construction creates at most 16 merged groups of four patch rows per full window and keeps the same window assignment between local blocks. The model permutes hidden rows and cosine/sine RoPE into window order. Exact F must keep each window's **original packed patch rows**, original RoPE coordinates, edge-window lengths, image/frame ownership and reverse permutation. At block 7, E needs the entire tensor for the affected image/frame in the native packed window order. The vision model then runs the rest of its original tower, applies the merger and uses the original post-merger inverse permutation before publishing an LM-ready embedding. [Pinned config](https://huggingface.co/Qwen/Qwen2.5-VL-7B-Instruct/raw/cc594898137f460bfe9f0759e9844b3ce807cfb5/config.json) · [Nonoverlapping patch embed](https://github.com/vllm-project/vllm/blob/v0.26.0/vllm/model_executor/models/qwen2_5_vl.py#L532-L558) · [Window order and packing](https://github.com/vllm-project/vllm/blob/v0.26.0/vllm/model_executor/models/qwen2_5_vl.py#L761-L796) · [Full path and inverse permutation](https://github.com/vllm-project/vllm/blob/v0.26.0/vllm/model_executor/models/qwen2_5_vl.py#L1075-L1125)

D also needs approximately 263 MiB of BF16 attention and MLP matrices for the seven local blocks, using `7 × (4 × 1280² + 3 × 1280 × 3420) × 2` bytes before biases, norms, patch embed, workspace or graphs. That analytic estimate applies when only the partial vision tower is loaded. Measure the actual D reservation and compare with equivalent Decode KV capacity. [Pinned vision dimensions](https://huggingface.co/Qwen/Qwen2.5-VL-7B-Instruct/raw/cc594898137f460bfe9f0759e9844b3ce807cfb5/config.json)

A full-window BF16 return has `64 × 1280 × 2 = 163,840 B` or 160 KiB. The same window's actual model-dtype packed patch input would be `64 × 1176 × 2 = 150,528 B` or 147 KiB, before transport, processor or metadata. Returning states after sending similarly sized E-produced patch activations uses 320 KiB round trip. Formats, dtype conversion and copy intersections must be measured on the active runtime. The useful comparison is native **fused** E against

```text
max(E's kept-window execution, E→D dispatch + D window execution + D→E return)
  + gather, ordering and synchronization
  + original E global block and remaining encoder
```

SLO admission must account for already posted D KV READs and current Decode work. An unreturned live window blocks E's global stage. A fallback can recompute a not-yet-committed window on E, but the dispatched D work and any tail interference still count. Compare same-device window sharding, fixed remote fraction, stage-local layer yields and a deadline-gated remote policy against whole-image offload and stock native. Measure actual packed changes, elapsed critical path and BF16 parity on fused and split shapes before any Online result. Physical validation must measure the copies and intermediate-state lifetimes against Decode deadlines. [Previous NIXL and temporal measurements](https://github.com/jyssys/MLLM-EP/blob/f5d6d70d750ea7b0a2c9f0599e874c07d4a5409b/poc_flashvep/reports/mllm_epd_decode_idle_fragmentation.md)

An additional candidate is first-decoder-layer visual-row RMSNorm and QKV/RoPE before the previous LM KV is ready. That producer is row-local once the original prompt metadata fixes MRoPE. Layer-0 attention still needs earlier rows, and subsequent blocks cannot run independently. With this checkpoint a BF16 visual embedding row is 7,168 B, projected Q/K/V together are 9,216 B, and K/V alone are 2,048 B. Sending complete precomputed QKV to P can add a larger payload than receiving the original embedding while leaving the residual input and first-layer causal attention on P. This analytic screen gives the idea lower priority unless D is the committed consumer and can retain the projection locally. Prior generic operator sharing is the relevant baseline.
