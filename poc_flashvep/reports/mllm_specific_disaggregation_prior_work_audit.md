# MLLM-specific disaggregation prior-work audit

Visual Understanding–Reasoning Disaggregation asks whether exact modality-aware placement of work in a dense MLLM provides a useful systems distinction. Visual Memory–Generation Disaggregation asks whether exact decode with resident visual K/V has a favorable crossover against generic parallelism. The underlying ingredients already have strong precedents. This campaign can establish a contribution through matched causal evidence or a measured architectural crossover.

## Multimodal serving and the existing EPD boundary

| Work | Mechanism and implication for this campaign |
| --- | --- |
| EPD Disaggregation, Singh et al. | Separates multimodal encoding, language prefill and decode on dedicated resources. Characterizes variable encoding cost and uses stage-specific resource allocation and encoder optimizations. The E/P/D partition is the starting baseline. [ICML 2025](https://proceedings.mlr.press/v267/singh25d.html) |
| TriInfer | Uses hybrid EPD and stage-level batching with heterogeneous instances and flexible resource scheduling. Its contribution overlaps macro-stage utilization and serving design. This campaign's B2/B3 distinction needs evidence inside the dense LLM after vision encoding. [MLSys 2026](https://proceedings.mlsys.org/paper_files/paper/2026/hash/f068c65585985c25c17f221390774ec7-Abstract-Conference.html) |
| RServe or REDServe | The arXiv title uses RServe and the abstract uses REDServe. It overlaps multimodal encoding and language-model forward within a request and schedules token-budgeted chunked prefill across requests. Encoder-to-LLM overlap and per-request scheduling already have direct prior art. [arXiv:2509.24381](https://arxiv.org/abs/2509.24381) |
| EAServe | Uses adaptive encode micro-batching, rate-controlled partial prefill offload to a co-resident GPU worker, dynamic SM partitioning and capacity-guided configuration. It establishes a close precedent for using otherwise idle resources in EPD and for evaluating stage capacities before picking placements. [PACT 2026](https://arxiv.org/abs/2609.31551) |
| ModServe | Measures variable multimodal demand in both decoder-only and cross-attention models. Modality-aware stage scheduling, adaptive scaling and resource disaggregation address bursty production traces. A modality label in the serving control plane therefore carries limited novelty by itself. [SoCC 2025](https://arxiv.org/abs/2502.00937) |
| DistServe | Separates prefill and decode for stage-specific latency SLOs and goodput. Its handoff moves prefetched KV from the P side to the D side. | MPIC | Caches multimodal K/V across differing contexts and placements, stores it on disk and combines reuse with selective recomputation. [arXiv:2502.01960](https://arxiv.org/abs/2502.01960) |

## Track B · Visual Understanding–Reasoning Disaggregation

FastV uses observed attention redundancy to prune visual tokens after early layers. HiMAP explicitly attributes visual information routing to different interactions across LLM depth and uses hierarchical pruning. Both establish prior art for a modality-by-depth phenomenon. They motivate, but cannot substitute for, measurements on the pinned Qwen revision and the Discovery200 distributions. [FastV, ECCV 2024](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/10478.pdf) · [HiMAP, CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Yin_Lifting_the_Veil_on_Visual_Information_Flow_in_MLLMs_Unlocking_CVPR_2025_paper.html)

Pathways of Visual Information Flow already uses causal patching and attention knockouts to distinguish direct visual readout from text-mediated transfer. Prompt and task can change the predominant path, and an intervention can induce a backup route. Rethinking Visual Token Retention directly intervenes on modality access across layer depth and generation time and finds non-uniform influence. This makes a generic observation that image attention varies by depth, task or generation step insufficient for a new causal claim. [Pathways, arXiv:2607.03358v2](https://arxiv.org/abs/2607.03358v2) · [Rethinking Visual Token Retention, arXiv:2611.28684](https://arxiv.org/abs/2611.28684)

| Test | Comparison needed for a specific claim | Evidence ceiling |
| --- | --- | --- |
| B1 modality × layer dependence | Contrast visual, prompt text and generated text under fixed original positions. Report per-query key-normalized mass or a matching token-count control alongside raw mass. Keep image geometry and dense layer scope visible. | Attention dependence is descriptive. Long visual prefixes mechanically absorb more mass, so raw mass can overstate preference. |
| B2 work-matched causal interventions | Localize residual Q/MLP paths versus permitted visual/text K/V access, with equal-cardinality or work-matched controls. Hold mask/sham overhead, generation or teacher-forced prefixes, and query support constant when comparing causal effects. | A localized effect can justify a placement study. Activation removal and attention masking change model semantics, even when the GPU executes the same dense work. |
| B3 exact row placement | Preserve original causal dependencies, MRoPE, Q/K/V, residual and dense projection work. Compare modality Q rows with equal-work generic row/sequence placement and relevant tensor, pipeline and context parallel controls. Charge scatter, advance synchronization, collective and shared-weight costs. | A useful effect needs a measured crossover with semantics and resources controlled. A causal difference or operator-only timing does not establish full serving benefit. |

Qwen uses shared dense weights for visual and text token rows after embedding. Treating an image token as a separate model replica changes memory budget. A row partition with shared weights needs a concrete mechanism and system counterfactual. Causal prefix dependencies, dense matmul tile utilization, ragged rows and repeated synchronization can dominate any advantage from visual-text allocation.

MegaScale-Infer places attention and MoE FFNs separately and pipelines microbatches between them. The disaggregation axis is operator and expert ownership across a sparse serving architecture. Applying operator placement to a dense MLLM therefore needs a new accounting of identical dense work, activation traffic and the realized cross-rank shapes. [MegaScale-Infer, SIGCOMM 2025](https://doi.org/10.1145/3718958.3750506)

## Track A · Visual Memory–Generation Disaggregation

FlashAttention established IO-aware exact attention and stable block-wise softmax. Flash-Decoding parallelizes decode attention over K/V segments and merges chunk results using log-sum-exp. vLLM DCP distributes KV along the sequence within a context-parallel group and combines attention results. They are the direct algorithmic baseline for an exact visual/text KV partition, including cases with unequal shard sizes. [FlashAttention](https://arxiv.org/abs/2205.14135) · [FlashAttention-2](https://arxiv.org/abs/2307.08691) · [Flash-Decoding](https://crfm.stanford.edu/2023/10/12/flashdecoding.html) · [vLLM context parallel deployment](https://docs.vllm.ai/en/latest/serving/context_parallel_deployment/)

For a fixed query, worker shards each form a local exponent scale, denominator and value-weighted numerator. Merging both numerators and denominators with the common largest scale gives the same mathematical softmax as the full K/V set. Floating-point reduction order and BF16 kernels still require numeric and output validation. Visual K/V residency specializes the shard boundary by modality. It leaves the attention merge itself as an established generic primitive.

TKNP decouples dense layer-weight placement from attention ownership. It keeps each request's full K/V local to its request owner and routes current-token activations through a rotating layer-block owner. This avoids the cross-node partial-attention merge in TKNP's design. Track A instead places two portions of one request on different devices, which requires merging across those portions for every applicable layer and generation step. The two schemes expose different network and memory costs. [TKNP, arXiv:2611.13293](https://arxiv.org/abs/2611.13293)

LOOK-M, VL-Cache, AirCache, MM-ShiftKV and HybridKV provide precedents for selection, pruning and compressed multimodal KV state. Visual Cache Reuse and MPIC add partial reuse, selective handling or offloaded storage. This campaign's exact Track A may retain full BF16 K/V while placing partitions separately. If an approximate variant later evicts, compresses or selectively loads only some content, it belongs to a different evidence class with quality and reconstruction controls. [LOOK-M](https://aclanthology.org/2024.findings-emnlp.235/) · [VL-Cache](https://proceedings.iclr.cc/paper_files/paper/2025/hash/00db17c36b5435195760520efa96d99c-Abstract-Conference.html) · [AirCache](https://openaccess.thecvf.com/content/ICCV2025/papers/Huang_AirCache_Activating_Inter-modal_Relevancy_KV_Cache_Compression_for_Efficient_Large_ICCV_2025_paper.pdf) · [MM-ShiftKV](https://arxiv.org/abs/2607.22586) · [HybridKV](https://arxiv.org/abs/2604.05887) · [VisMemo](https://arxiv.org/abs/2610.25136)

The measured comparison should include single-device full-cache decode, balanced generic context splitting, fixed-prefix versus growing generated K/V and the true image/text/generated partition. Match total K/V rows or explicitly report load skew. Preserve physical placement and rank accounting across controls. Sum source-to-shard materialization, bytes holding original/duplicate backing storage, per-step Q/partial-result/statistics movement for all 28 layers, synchronization latency, and decode batch changes separately. Large visual ratios may enlarge the critical shard even as the other device acquires capacity. An exact merge test can establish correctness but cannot quantify the cost of inter-device execution.

## Evidence carried from earlier H200 campaigns

The previous wide-batch QPS5 pilots found that Static10 under Free and B4 worsened TTFT p95 by 43.9% and 42.4% versus same-cap NativeCommon. The prepared decode batch fell to one in the separate counter runs. Idle10 retained batching and reached 94% and 92% Decode SLO. The following slice-aware campaign recovered tested exact N1/N8 under symmetric P/D BI1 and demonstrated lower physical EC clone traffic at the same cut. Its active BI1 B-new moved 1,482 tokens for one Main100 request at QPS5 and reported TTFT p95 20.317 s with 75% Decode SLO, versus the matched Native observer's 17.215 s and 75%. These are prefill-suffix and EC transport observations, including different numerical settings. They motivate investigating the two distinct placements while keeping their evidence out of a new matched claim. [Wide-batch final](mllm_epd_h200_wide_decode_batch_final_summary.md) · [Slice-aware final](mllm_epd_h200_dynamic_slice_aware_final_summary.md)

The conservative novelty boundary is a measured, model- and workload-specific opportunity that survives those generic controls, including evidence when a visual partition loses. A system contribution requires a reproducible exact implementation and a net advantage after placement and transport costs. Mechanism observations, local kernels, simulations and end-to-end runs carry separate evidence levels.
