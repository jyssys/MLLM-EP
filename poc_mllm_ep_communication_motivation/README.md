# MLLM MoE EP communication motivation PoC

Bounded TRUE-EP4 characterization only. It measures DeepEP dispatch/expert/combine stages, exact visual/text route payload, frozen-route modality-isolated replays, and controlled prefill/decode interference. It does not implement communication-only chunking.

The final verdict is in `reports/final_summary.md`; exact commands and evidence labels are in `reports/reproduction.md`. Pushable compact results live in `artifacts/results/`, while append-only raw runs remain local and are ignored because they total over 100 MiB.
